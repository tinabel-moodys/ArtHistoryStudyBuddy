# ArtStudyBuddy
Art history study and review app


## Run

```
npm install
npm start
```

Electron app. Create exams with Must Know Works / Must Know Terms (add manually or import a markdown file — see `sample-exam.md`). Study with flashcards or multiple-choice quizzes; scores are saved per exam. Artwork data from the Met Museum Open Access API and Wikimedia Commons; term definitions from Wikipedia (each answer links its source).
